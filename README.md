# s4way

my personal portfolio page. next.js + tailwind, fully static.

## run

```bash
npm install
npm run dev
```

dev server runs at http://localhost:3000

## build

```bash
npm run build
```

static output lands in `out/`.

## writing a blog post

drop a `.md` file in `src/posts/` with frontmatter:

```md
---
title: my post
date: 2026-11-17
description: one line about it
---
```
